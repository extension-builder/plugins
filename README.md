# JCB plugins

The 18 plugins connected to Joomla Component Builder, maintained here as
reviewable plugin source for transfer back into JCB definitions.

This migration changes authored methods and their required imports. Generate
the installable Joomla 6 packages with JCB after applying those changes to the
maintained definitions; the checked-in provider, installer and class scaffolding
remain the original generated reference and are not hand-upgraded packages.
